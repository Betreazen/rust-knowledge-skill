# rust-knowledge

Agent Skill для разработки на Rust в любой области: библиотеки, CLI, web-бэкенды, async-сервисы, embedded, WebAssembly, FFI, данные и ML, GUI, игры.

Скилл даёт ИИ-агенту (Claude Code, claude.ai и другим инструментам с поддержкой формата [Agent Skills](https://agentskills.io)) три вещи:

- **библиотеку знаний** — более 500 ссылок на книги, статьи, доклады, крейты и кодовые базы, разложенных по категориям. У каждой ссылки есть автор, год и пояснение, зачем её читать;
- **тулчейн** — обязательные и ситуативные инструменты (clippy, rustfmt, cargo-nextest, cargo-deny, Miri, criterion, samply и другие): установка, команды, порядок шагов в CI, шаблоны `[workspace.lints]` и профилей сборки;
- **пайплайн** — тесты до кода, проверки качества, бенчмарки, базовый замер, ревью, поиск решений в библиотеке, оптимизация и повторный замер. Правка оптимизации принимается, только если бенчмарк показал выигрыш.

Состояние знаний — октябрь 2026: стабильный Rust 1.99, edition 2024. Тексты справочников на русском, названия источников — в оригинале.

## Состав

```
rust-knowledge/
├── SKILL.md                              точка входа: куда смотреть и как работать
└── references/
    ├── pipeline.md                       пайплайн разработки и оптимизации
    ├── toolchain.md                      инструменты, команды, CI, линты, профили
    ├── performance.md                    оптимизация: таблица «симптом → техника → источник»
    ├── idioms-patterns.md                паттерны и антипаттерны, чеклист ревью
    ├── architecture.md                   крейты, workspace, слои, тесты, feature flags
    ├── concurrency-async-unsafe.md       потоки, async, атомики, unsafe, FFI
    ├── domains.md                        особенности десяти областей разработки
    └── books.md                          книги и маршрут чтения по уровням
```

Агент загружает `SKILL.md`, когда задача касается Rust. Справочники он открывает только тогда, когда нужен конкретный раздел, поэтому скилл почти не занимает контекст, пока не используется.

## Установка

**Claude Code: для всех проектов**

```bash
git clone https://github.com/Betreazen/rust-knowledge-skill.git
cp -r rust-knowledge-skill/rust-knowledge ~/.claude/skills/
```

**Claude Code: для одного проекта.** Скопируйте папку `rust-knowledge` в `.claude/skills/` в корне проекта и закоммитьте её. Тогда скилл получит вся команда.

**claude.ai.** Заархивируйте папку `rust-knowledge` в zip и загрузите в разделе Skills настроек claude.ai. Во frontmatter только стандартные поля `name` и `description`, поэтому загрузка проходит без ошибок.

**Другие агенты (Codex, Gemini CLI, GitHub Copilot, Cursor).** Скопируйте папку в `.agents/skills/` проекта. Этот путь читают большинство инструментов с поддержкой Agent Skills.

## Использование

Скилл срабатывает сам, когда задача касается Rust: написание или ревью кода, выбор крейтов и инструментов, архитектура, профилирование и оптимизация. В Claude Code его можно вызвать и явно командой `/rust-knowledge`.

Примеры запросов:

- «Настрой для этого крейта clippy, nextest и cargo-deny и предложи CI»
- «Профиль показывает много времени в `HashMap::insert` — что можно сделать?»
- «Сделай ревью модуля по чеклисту идиоматичного Rust»
- «Проведи цикл оптимизации парсера: бенчмарки, базовый замер, гипотезы из библиотеки, повторный замер»
- «Как разбить проект на крейты, чтобы ускорить сборку?»

## Пометки в справочниках

- `[устарело]` — у материала есть замена, и она указана рядом.
- `[не проверено]` — утверждение взято из одного вторичного источника; его стоит перепроверить.

Версии крейтов и статус стабилизаций указаны на октябрь 2026. Со временем они устаревают, поэтому перед важными решениями сверяйтесь с crates.io и release notes Rust.
